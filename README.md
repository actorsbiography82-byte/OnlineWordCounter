# ToolCraft Hub & Developer Utilities

A suite of 100% client-side, zero-ad, standalone browser utilities engineered for pure speed and total privacy.

---

## 🛠 Included Standalone Tools

1. **ToolCraft Hub (`index.html`)** — Directory dashboard featuring instant search and keyboard shortcuts (`/`).
2. **TextCraft (`textcraft.html`)** — Text Formatter, Online Word Counter, Case Converter (UPPERCASE, lowercase, Title Case), and real-time Social Media limits (Twitter/X 280, Meta description 160, LinkedIn, Instagram).
3. **PassCraft (`passcraft.html`)** — Cryptographically secure password generator using the browser's native `window.crypto.getRandomValues` (CSPRNG) with real-time entropy strength analysis.
4. **QRCraft (`qrcraft.html`)** — Instant high-resolution QR code generator for URLs, Wi-Fi, and text with custom colors, error correction, and 1024px PNG & vector SVG downloads.
5. **Base64Craft (`base64craft.html`)** — Bidirectional UTF-8 compliant Base64 encoder and decoder with emoji support, error shielding, and one-click swapping.

---

## 🚀 Key Features

* **Zero Build Steps**: Pure HTML5, Tailwind CSS (via CDN), and Vanilla JavaScript.
* **100% Client-Side Privacy**: Data never leaves your machine. No telemetry, no cookies, no tracking.
* **Instant Deployment**: Drag and drop the folder directly into [Vercel](https://vercel.com) or [Netlify Drop](https://app.netlify.com/drop).
* **Mobile-First Responsive**: Engineered with Plus Jakarta Sans and JetBrains Mono typography.

---

## 💻 Local Usage

Simply double-click `index.html` to open in any web browser, or serve with any static web server:

```bash
npx serve .
# or
python -m http.server 8080
```
